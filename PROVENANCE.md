# Verify source provenance
Run `node scripts/fingerprint.mjs` on a trusted checkout to generate fingerprint.json. Keep the manifest separately from the copy being checked. Place that trusted manifest in the candidate checkout and run `node scripts/fingerprint.mjs --verify`. This compares selected source, script, example, test, logo and license files byte for byte using SHA-256. Compare against a known official Git commit or trusted CI artifact; a manifest generated by an unknown distributor is not proof of origin. Modified copies may have different hashes while remaining lawful. This is not a digital signature, license enforcement or tracking mechanism. No network calls are made. Extra files outside the selected paths are not covered.
