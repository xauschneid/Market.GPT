# Public roadmap
## Current 0.1.x
- Deterministic analysis of supplied signals and optional Kolibri explanation.
- Standalone REST and JavaScript interfaces.
## Proposed contributions
- Validate real Kolibri inference and document reproducible setup.
- Add API integration tests and more edge cases.
- Add optional generic OHLCV input analysis with documented formulas.
- Publish tagged releases after successful tests.
## Out of scope
News feeds, proprietary Vaelis strategies, market brain, personal brain, customer data, automated execution. No adoption or performance claims without evidence.
